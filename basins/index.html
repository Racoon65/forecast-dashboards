Как получены цифрыHow the numbers are produced
  • Прогноз: модель WeatherNext 3, среднее по ансамблю, шаг сетки 0.1°. Диапазон P10–P90 ориентировочный.
  • Каждая ячейка рельефа (SRTM, 3″) относится к высотной зоне с шагом 500 м и к ближайшему узлу сетки модели. Слой осадков — среднее по площади.
  • Твёрдые и жидкие осадки разделяются по пороговой температуре (формула Глазырина): Tкр = 1.25 + 0.016·Z + 0.207·Z², где Z — высота в км. Если температура воздуха не выше пороговой, осадки считаются твёрдыми.
  • Температура воздуха берётся из модели без высотной поправки.
  • Опасные явления определяются по среднему слою осадков в высотной зоне: берётся наибольшая сумма за любые 12 часов подряд, отдельно для жидких и для твёрдых осадков.
  • Данные обновляются, когда запускается блокнот расчёта: он записывает их в файл data.json рядом с этой страницей (последние 30 расчётов). Страница читает его при каждом открытии.
  • В списке «Показан расчёт» собраны все сохранённые расчёты. Блокнот при каждом запуске добавляет в архив новый расчёт и те прежние файлы Excel, которых в архиве ещё нет.
  • Forecast: WeatherNext 3 model, ensemble mean, 0.1° grid. The P10–P90 range is indicative.
  • Each terrain cell (SRTM, 3″) is assigned to a 500 m elevation zone and to the nearest model grid node. Precipitation depth is the area mean.
  • Solid and liquid precipitation are separated by a threshold temperature (Glazyrin formula): Tcr = 1.25 + 0.016·Z + 0.207·Z², where Z is elevation in km. If the air temperature is not above the threshold, precipitation counts as solid.
  • Air temperature is taken from the model without an elevation correction.
  • Hazards are assessed from the mean precipitation depth in an elevation zone: the highest total over any 12 consecutive hours, separately for liquid and solid precipitation.
  • Data are updated when the calculation notebook is run: it writes them to the data.json file next to this page (the latest 30 runs). The page reads it each time it is opened.
  • The “Run shown” list holds all saved runs. On every run the notebook adds the new run to the archive, along with any earlier Excel files not yet in it.
